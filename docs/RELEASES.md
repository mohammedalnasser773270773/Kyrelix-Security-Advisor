# Releases and Downloads

## Official Release Information

Kyrelix Security Advisor is currently in development. Do not consider any APK, store listing, download link, or proposed release date official unless it is published and verified by the project owner.

If releases are published through GitHub, each one should state:

- Version number and release status.
- Supported Android versions and compatibility notes.
- A concise list of changes and known limitations.
- The officially approved distribution channel and any available integrity information.

Release artifacts must be signed and traceable through the project's established release process.

## Safe Distribution

Never publish debug builds, signing keys, keystores, service-account files, credentials, source archives, database exports, or user information as public release assets.

Before publishing screenshots, remove personal email addresses, phone numbers, session identifiers, authenticator QR codes, recovery information, and other sensitive details.

## Source Code

This repository is for documentation and public release information. It does not distribute the proprietary application source code.
